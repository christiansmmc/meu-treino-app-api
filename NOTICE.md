# Third-party notices: exercise catalogue

The API's own code is not covered here. This file covers the exercise catalogue data and media:

| File | What |
|---|---|
| `data/exercises.json` | the global exercise catalogue loaded by `bun run catalog:sync` |
| `data/media-manifest.json` | per-file source URL, licence, credit and colour transform of every image |
| `data/credits.json` | the sources, for an in-app credits screen |
| image files under `MEDIA_DIR` (`sources/...`) | downloaded, colour-normalized, aligned, cropped and resized by `bun run media:fetch` (`src/media/`) |

They are generated by [`scripts/catalog/`](scripts/catalog/README.md) (`build-catalog.mjs` plus its override and
review files), which is also the corresponding source for the modifications described below. The catalogue
combines material under three licences.

| What | Where it shows up | Source | Licence |
|---|---|---|---|
| English names, muscles, equipment, category, English instructions | `nameEn`; `target`, `secondaryMuscles`, `equipment`, `category` (translated here) | ExerciseDB v1, via openGym | MIT |
| Portuguese names and instructions | `name`, `instructions` | openGym `catalogue/i18n/pt-BR.json` | AGPL-3.0 |
| Exercise illustrations | `images`, `mediaAttribution` | Workout Guide, Everkinetic | CC BY-SA 4.0 |

The Brazilian Portuguese names and instructions come from **openGym**, Copyright (C) 2026 Duarte Santos,

## 3. Illustrations (CC BY-SA 4.0)

The images are downloaded from their original repositories, renamed to
`sources/<source>/<id>/frame-<n>.v2.png` (`n` = the upstream frame number) and **modified** by
`media:fetch` (`src/media/normalize.ts`, `src/media/frames.ts`):

1. Colours, so every frame is white strokes on a transparent background (the `transform` of each file in
   `data/media-manifest.json`):
   - `luma-to-alpha` (Everkinetic): the black-on-white line art becomes white on transparent
     (alpha = 255 − luma, colour = white);
   - `to-white` (Workout Guide): the strokes, already white on transparent but partly off-white (RGB 254),
     are set to pure white; the alpha channel is kept as is.
2. Framing, per exercise (all frames of a folder together, so they stay aligned as an animation): the
   Everkinetic frames, cropped separately upstream, are translated onto the first frame (`align:
   register`); then every frame is cropped to the bounding box of the strokes of all frames of the
   exercise plus a 6% margin, placed on a transparent square canvas and downscaled to at most 512 px
   (area averaging). The drawings themselves are not retouched.

Some Workout Guide frames are not used at all (frames drawn in a different line style or framing from the
exercise's first frame; `scripts/catalog/media-frame-exclude.json`); leaving a frame out does not modify the
others.

These adapted images are licensed under the same [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
licence. Per-file credit and the change made are in `data/media-manifest.json`; each exercise carries a short
credit in `mediaAttribution` (ending in "(cores adaptadas)"); `data/credits.json` lists the sources for a
credits screen.

- **Workout Guide** by Bryl Lim (<https://bryllim.com>), <https://github.com/bryllim/workout-guide>,
  CC BY-SA 4.0. Three frames per exercise, 512×512 PNG, white strokes on a transparent background. For many
  exercises the first frame is adapted by Bryl Lim from an Everkinetic illustration (rasterized, recolored,
  vector-traced); the manifest names the Everkinetic original for each of those frames.
- **Everkinetic**, <http://everkinetic.com>, <https://github.com/everkinetic/data>, CC BY-SA 4.0.
  Two frames per exercise (relaxation, tension), black line art PNG.

### Sources evaluated and not used

- **wger** (<https://wger.de>): images are user uploads with a per-image CC BY-SA 3.0/4.0 declaration that
  cannot be verified. A visual check of the matched images found re-uploaded commercial stock renders
  (one with a watermark), unflagged AI art and stock-style photos. `build-catalog.mjs` therefore accepts
  only wger images credited to Everkinetic (PNG only, colour-normalized like Everkinetic's); none of those
  won a match in the current build, so the current catalogue has no wger images. If some are selected later,
  their author and licence are recorded per file in `data/media-manifest.json` and in `data/credits.json`.
- **RepDB**: excluded entirely (its licence is not open).
